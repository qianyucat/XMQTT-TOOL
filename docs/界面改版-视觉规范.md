# XMQTT Tool 界面改版设计规范

> 版本：v2「精密仪表」 · 2026-11 · 适用：Electron 桌面端（Windows / macOS / Linux）
> 原则：**布局骨架、DOM 结构、class 命名、栅格尺寸一律不动**，只重做视觉层与状态表达。

> ⚠️ **视觉层已被 v3 取代**（扁平形态 + 磨砂材质 + 新字族），当前生效的规范见
> [界面精修-v3-扁平磨砂.md](./界面精修-v3-扁平磨砂.md)。本文保留为 v2 的设计记录：
> 结构、断点、几何断言与「刻意不改的东西」仍然有效，色板 / 字阶 / 阴影部分已过期。

---

## 1. 改版目标与边界

| 目标 | 做法 | 不做什么 |
| --- | --- | --- |
| 长时间盯屏不累 | 重排中性灰阶、把文字对比度全部拉到 AA 之上 | 不加大字号破坏 28px 行高与虚拟滚动 |
| 一眼分出主次 | 「一个强调色只做一件事」：填充与文字分两支 | 不用装饰性渐变、发光、彩色边框堆视觉 |
| 状态可被认出 | 连接 / 选中 / 订阅 / 禁用 各有一套固定表达 | 不改按钮位置、不新增工具条 |
| 深浅主题同源 | 全部走 CSS 变量，组件层零主题分支 | 不动 `glass.ts` 的判定与窗口参数 |

约束来自项目既有硬规则（见 `AGENTS.md`）：`--table-row-h` 是虚拟滚动唯一行高来源；
`.col-*` 同时挂 th/td；窄档位列宽必须是纯百分比；顶栏可交互控件必须显式 `no-drag`。
本次改动**没有触碰其中任何一条**。

## 2. 现状诊断（改版前）

| # | 问题 | 证据 | 影响 |
| --- | --- | --- | --- |
| 1 | 浅色主题文字压线 | `--muted #6b7a90` 在白底 **4.36:1**，且大量 11px 标签用它 | 小字发灰，浅色「一整片白」 |

## 3. 设计方向：精密仪表（Calm Instrument）

仪表不是靠装饰显得专业，而是靠**读数清楚**。三条可执行原则：

1. **颜色只做一件事。** 强调色分两支：`--accent` 只用于文本 / 图标 / 边框 / 焦点环（要亮）；
   `--accent-fill` 只用于实心填充（要深，白字才够 4.5:1）。计数、卡片装饰条一律退回中性。
2. **层级靠「面 + 边」，不靠投影堆叠。** 五级中性面（画布 / chrome / 面板 / 次面 / 浮层）+ 一条结构线，
   深色下即使玻璃让底透上来，也能看出哪块是板。
3. **数据表里，只允许一个主角。** 主题列最亮；时间、QoS、R/D、长度、预览依次后退。
   行高、列宽、虚拟滚动全部保持原样。

| 令牌 | 深色 | 浅色 | 用法 |
| --- | --- | --- | --- |
| `--accent` | `#6aa9ff` | `#1568c4` | 文本、图标、边框、焦点环、选中竖条 |
| `--accent-hover` | `#8bbcff` | `#0f56a6` | 文本型强调的 hover |
| `--accent-fill` | `#2f6fe4` | `#1a6fd4` | 主按钮 / 角标 / 开关（配白字） |
| `--accent-fill-hover` | `#3d7cf0` | `#1560bd` | 填充 hover |

| `--danger` | `#ff7373` | `#c23b3b` | 错误 / 危险操作 |

### 4.3 对比度（实测，WCAG 2.1）

| 组合 | 改版前 | 改版后 | 结论 |
| --- | --- | --- | --- |
| 正文 / 深色面板 | 13.58:1 | **14.40:1** | AA / AAA |
| 次级文字 / 深色面板 | 8.06:1 | **8.86:1** | AA / AAA |
| 辅助文字 / 深色面板 | 4.80:1 | **5.33:1** | AA |
| 正文 / 浅色面板 | 15.66:1 | **16.44:1** | AAA |
| 次级文字 / 浅色面板 | 7.49:1 | **8.35:1** | AAA |
| 辅助文字 / 浅色面板 | **4.36:1 ✗** | **4.76:1 ✓** | 修好 |
| 白字 / 主按钮（深色） | **3.01:1 ✗** | **4.65:1 ✓** | 修好 |
| 白字 / 主按钮（浅色） | 4.63:1 | **4.92:1** | AA |
| 强调色文字 / 深色面板 | 5.48:1 | **6.96:1** | AA |

> 结构分隔线（1px 面板边）按装饰性处理，不承诺 3:1；**控件边界**用 `--border-strong` 加深，
> 并由 3px 焦点环承担「当前在哪」的信息 —— 焦点环对比度 ≥ 3:1。

### 4.4 其余刻度（保持不变）

间距 4px 基线、控件高度 30 / 26 / 22、`--table-row-h: 28px`、圆角 4/5/6/8/12、
动效 90 / 140 / 220ms 与两条缓动曲线，均沿用原值。阴影只调了档位强度：
深色 `0 1px 2px / 0 6px 18px -6px / 0 24px 60px -14px`，浅色改用冷调灰避免发脏。

## 5. 字阶与层级

| 角色 | 规格 | 说明 |
| --- | --- | --- |
| 视图标题 | 13.5px / 600 / `--text` | 「消息」「发布消息」 |
| 分区标题 | 11.5px / 600 / `--text-2` / 0.02em | 取消 `uppercase`：中文没有大小写，混排时节奏会乱 |
| 表头 | 11px / 600 / `--text-2` / 0.03em | 比正文小，但不比正文淡 |
| 表格正文 | 12.5px | 行高仍 28px |
| 表格主角（主题） | 12.5px 等宽 / `--text` | 靠颜色而不是字重拉出层级 |
| 辅助（时间 / 预览） | 11–12px / `--muted` | 可读但不抢 |
| 编号 / 统计值 | 22px / 600 / tabular-nums | 状态页数字 |
| 代码 / JSON | 12px / 1.7 / `--text-2` | 缩进 `tab-size: 2` |

字体栈不变（`Segoe UI` / `Microsoft YaHei UI` / `PingFang SC`，等宽 `Cascadia Mono` / `SF Mono`），
不引外链字体 —— 离线机器必须能跑。

## 6. 组件规范

### 6.1 按钮

- 次级按钮：`--panel-2` 底 + `--border-strong` 边 + `shadow-1`，hover 变 `--elevated` 并加一层柔影。
- 主按钮：`--accent-fill` 实心 + 顶部 1px 内高光，**禁用时退回中性面**（0.6 透明度），
  避免「不能按的那颗比能按的更抢眼」。
- 顶栏图标按钮默认无框，hover 才给底色与描边；弹层关闭按钮同理。
- 已连接状态下，`#btnConnect` 禁用时用相邻选择器把强调转移到 `#btnDisconnect`（淡蓝底 + 蓝字），
  DOM 与组件变体都不动。

### 6.2 输入 / 下拉

- 边界统一 `--border-strong`；hover 再深一档；focus 为 `--accent` 边 + 3px `--accent-soft` 环。
- 下拉箭头改为内联 SVG 折线（原来两个 45° 渐变拼的三角，在 125% 缩放下有阶梯）。
- 卡片内的编码下拉按内容宽度（`width: auto; min-width: 84px`），不再拉满半张卡。

### 6.3 表格（消息表 / 状态订阅表）

- 表头 sticky，**玻璃模式下用实色 `--panel-2-solid`**：0.978 alpha 在软件光栅下会透出滚动行。
- 行线为 `color-mix(--border 90%)`；hover 为 `--hover-wash`；
  选中行为 14% 强调色底 + 左侧 2px 竖条（不靠颜色也能定位）。
- 数字列对齐：长度右对齐（个位对齐才能比大小），QoS / R/D 居中。
- 主题列只提亮不加重；预览降到 `--muted`。

### 6.4 主题树

- 已订阅 = 9% 成功色底 + 左竖条 + 高亮主题名。不再整行铺 `success-soft`：
  连续几个订阅节点会连成亮绿色块，把树枝干的层级压掉。
- 节点数字用 10.5px 中性胶囊（带 1px 边），不再是浮在面板上的纯色块。

### 6.5 卡片与分组

- 状态页 `stat` 卡：10px 圆角、`--panel-2` 底、hover 抬边；**删掉每张卡顶部的 2px 渐变条**
  （六个卡片各一道，等于把强调色变成底纹，且不承载信息）。
- 连接详情 `kv` 收进一张卡（160px + 1fr 栅格不变），状态页订阅表加同规格边框与圆角。
- 订阅条目 8px 圆角，hover 只加深边界 + 一层柔影。

### 6.6 弹层 / Toast / 空态

- 弹层 16px 圆角、`shadow-3`、头部 15px 标题；关闭按钮无框。
- Toast 10px 圆角、左侧 3px 语义色条、`shadow-3`。
- 空态 12.5px / 1.7 行高 / `text-wrap: pretty`，不再是一行贴顶的小灰字。

## 7. 状态矩阵

| 状态 | 表达 | 实现 |
| --- | --- | --- |
| hover | 一层 5~6% 白（深）/ 4.5% 墨（浅） | `--hover-wash` |
| active | 下沉 1px + 更深一层 | `.btn:active` |
| focus | 2px `--accent` 外环 + 2px 偏移 | `:focus-visible` |
| disabled | 降透明度 + 去饱和，**不改变色相** | `.btn:disabled` |
| selected | 14% 强调色底 + 2px 竖条 | `.table tr.is-selected` |
| subscribed | 9% 成功色底 + 竖条 + 高亮名 | `.tree-row.is-subscribed` |
| offline | 需要连接的动作整体置灰锁点击 | `.is-offline .needs-connection`（沿用） |

## 8. 可访问性

- 文本对比度全部 ≥ 4.5:1（见 4.3 表）；主按钮、辅助文字两处原来的不合格项已修复。
- 状态不只靠颜色：连接状态同时有圆点、文字、语义色；订阅状态同时有底色、竖条、勾图标。
- 键盘：沿用 Radix 的焦点陷阱与 Esc 关闭；所有可聚焦元素共用同一套焦点环。
- 触屏：`pointer: coarse` 下 44px 行高 / 36px 控件保持不变（本次未改密度层）。
- 动效：`prefers-reduced-motion` 全量降级；`prefers-reduced-transparency` 时玻璃退回实色。

## 9. 刻意不改的东西

1. 三栏栅格 `380 / 1fr`、发布页 `1fr / 320`、导航 80 / 64px；
2. `--table-row-h`、列宽百分比、`.col-*` 的成对隐藏；
3. `glass.ts` 的材质判定与窗口参数、`app-region` 的 drag/no-drag 划分；
4. 视图切换、抽屉、拖动分隔栏等任何行为逻辑。

**唯一的行为修复**：服务器编辑器里重复渲染的「配置名称」（重复 DOM id）已去掉。

## 12. 下一步建议（本次未做）

1. **密度偏好**：在设置里给「紧凑 / 舒适」两档，只切 `--table-row-h`（30px 舒适档）与控件高度。
2. **列显隐与列宽记忆**：用户在宽屏排障时通常只看「时间 / 主题 / 预览」，可把这套偏好持久化。
3. **键盘优先**：`/` 聚焦过滤框、`J/K` 上下选消息、`Cmd/Ctrl+Enter` 发布。
4. **状态页留白**：状态页目前 60% 是空白，可加一张「最近 60 秒收发」的迷你折线（不改栅格，只填空白区）。
