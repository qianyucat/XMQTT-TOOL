# XMQTT Tool 界面规范 v3「扁平 · 磨砂」

> 版本：v3 · 2026-11 · 取代 [v2「精密仪表」](./界面改版-视觉规范.md) 的**视觉层**
> 边界不变：布局骨架、DOM 结构、class 命名、栅格尺寸、`--table-row-h` 一律不动。

v2 的层次感来自「描边 + 内高光 + 逐级投影」，v3 把这些全部收掉，只留两条规则：

- **形态扁平**：面与面靠填充差分层，分隔只用 1px 发丝线，卡片与按钮不带投影；
- **材质磨砂**：真正的「浮起来」只发生在磨砂层上（顶栏 / 导航 / 粘性表头 / 弹窗 / toast），
  它们半透明 + `backdrop-filter`，背后的东西被高斯模糊糊掉 —— 层级的表达是
  「看得见但读不清」，而不是「更深的投影」。

## 2. 字体

| 角色 | 字族 | 说明 |
| --- | --- | --- |
| UI | `Segoe UI Variable Text` → `Segoe UI` → `PingFang SC` / `Microsoft YaHei UI` | Win11 用光学尺寸版本，Win10 自动回落，中文按苹方→雅黑接 |
| 数字面 | `Bahnschrift` → `Segoe UI Variable Display` | DIN 家族，只给状态页读数与品牌名，字距 -0.02em |
| 等宽 | `Cascadia Mono` → `SF Mono` → `Consolas` | 只给主题 / 报文 / 日志，不当正文字体用 |

字阶：`10 / 11 / 12 / 13 / 14 / 16 / 22 / 28`，正文 13px，面板标题 14/600，
分区标签 11.5/600（靠字重而不是字号分主次），读数 26/600。

> 离线机器装不了 webfont（CSP 只允许 `font-src 'self'`，且 Windows 侧无外网），
> 所以字体个性只能从**系统字族 + 字重/字距/数字面**里取，不引第三方字体文件。

## 3. 磨砂模型

| 层 | 面积 | 半径 | 底色 |
| --- | --- | --- | --- |
| 顶栏 / 导航 | 窄 | `--blur-2` | `--frost-chrome`（0.62 深 / 0.70 浅） |
| 粘性表头 | 34px 高 | `--blur-1` | `--panel-2` 74%（玻璃档 80%） |
| 弹窗 | 中 | `--blur-3` | `--frost-panel` 0.86 + 遮罩 0.44 / 10px |
| Toast | 小 | `--blur-3` | `--frost-panel` |

**内容区不加 blur**：背后是同一条平滑渐变，糊与不糊没有视觉差别，只白烧一遍全屏采样。

实测（Win11 + `--disable-gpu` 软件光栅，80 条消息、45 帧连续滚动）：

```
磨砂表头 8.0ms/帧   实色表头 7.9ms/帧   → 偏差 0.1ms，可忽略
```

## 4. 组件要点

| 组件 | v3 做法 |
| --- | --- |
| 按钮 | 无投影、无位移；悬停只提亮填充 + 加深边界；主按钮纯 `--accent-fill` |
| 输入 / 下拉 | 1px `--border-strong`，聚焦换成 3px 半透明主色环（`--ring`） |
| 卡片（stat / kv / 订阅项） | 发丝描边 + 填充；**玻璃档下描边是结构不是装饰**（同色填充会让卡片整块消失） |
| 导航选中 | 平铺 `--accent-soft` 色块 + 30% 主色描边，保留滑动位移（回应操作，不是装饰） |
| 表格 | 行线 70% 边框色；选中行 13% 主色 + 左侧 2px 竖条；表头磨砂且随滚动出模糊 |
| 弹层 / Toast | 磨砂面板 + 18 / 12 圆角；toast 用左侧 3px 状态色条而不是整块染色 |
